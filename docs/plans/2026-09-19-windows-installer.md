# Windows 安装版

用户已选定：安装向导、可选目录、快捷方式、安装时带上主工作流 Skill。不使用子智能体或目标模式，不自动上传。

## 设计边界

- Windows x64、当前用户安装，不要求管理员权限。NSIS assisted installer，桌面和开始菜单入口，沿用书本图标。
- Electron 与 Python 随应用安装；固定版 cyz-edu-research 0.3.0 随包携带，安装时离线复制到 CODEX_HOME/skills（默认用户 .codex/skills）。
- 对捆绑 Skill 校验文件清单及 SHA256；已有不同内容则保留并明确提示，不覆盖。卸载不删除外部 Skill 或研究项目。
- 不携带账号、论文、MinerU 模型、未授权的附属 Skill。研究功能仍要求本机 Codex 登录；PDF 解析仍要求本机 MinerU。
- 安装包暂未签名；交付时如实说明，不绕过系统安全设置。

## 实施与验收顺序

1. 测试：新安装、重复安装、修改冲突、非法路径、损坏资源不写入。
2. 安全安装服务、内置 Python 选择、无窗口安装入口。
3. 固定下载校验与打包白名单、NSIS 安装向导与快捷方式。
4. 全部自动测试和实际打包；临时独立目录安装，验证 Skill、快捷方式、打开窗口、新项目初始化与卸载保留。
5. 更新本地使用说明、记录安装包哈希与验证范围。用户原项目不参与安装测试。
