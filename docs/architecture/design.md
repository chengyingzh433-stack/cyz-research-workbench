# CYZ 工作台 0.1.0 实施设计

采用用户已交付的 v0.2 工程契约及 v0.1 产品决策。2026-09-19 用户再次授权继续，禁止子智能体与目标模式；界面可视化已获同意。源码位于当前工作区的 work/projects/cyz-research-workbench。

## 实施选择

采用先接入验证、再项目服务、再桌面界面的顺序。先做完整界面会延迟暴露运行时不兼容；一次实现全部模块会难以定位故障。先验证连接与消息可将失败限制在小范围内。

Electron 主进程持有服务和受管 Codex 子进程，React 渲染三栏界面。共享 ProjectService 统一处理本机 API 与白名单 IPC；SQLite 管理任务、事件、租约和版本事务，Markdown 管理正文。研究内容只经版本发布服务写入正式项目，Codex 运行于独立 run 工作副本。

第一批只实现协议传输与兼容性探测，不启动研究 turn。协议来自本机 codex-cli 0.153.4 generate-ts；每次请求单独超时，断线时未确认请求标为结果未知，不重发。未知服务端请求返回不支持，审批需交给用户。标准输出只处理协议帧；不保存原始认证响应、stderr 或思维链。

界面预览使用标明为演示的材料，左栏阶段与资料，中栏成果，右栏对话。切换阶段不调用模型；任务进度与学术门检分开。实际连接、真实研究、Windows 分发尚待后续验证，不因原型可用而关闭 WB 项。

验证分层：传输及状态算法；临时数据库/文件集成；Electron UI；真实 Codex/MinerU。真实研究关键决定由用户作答。测试不会作为开发代理委派工作。
