# CYZ 研究工作台：Windows 安装测试版

这是首个公开的 Windows x64 安装测试版。它把材料、草稿版本和研究对话放进一个本地窗口，研究规则来自配套的 [CYZ 教育研究工作流 0.3.0](https://github.com/chengyingzh433-stack/cyz-edu-research/releases/tag/0.3.0)。如果只想在 Codex 中使用工作流，不必安装工作台。

## 下载哪个文件

- `CYZ-Research-Workbench-0.1.0-Setup-x64.exe`：安装程序，约 125 MiB。双击后可选择安装目录，安装完成后从桌面或开始菜单的书本图标打开。
- `SHA256SUMS.txt`：安装程序的 SHA256 校验值。
- `Windows-Quickstart.md`：安装、第一次使用和依赖说明，可以留在本地查看。

GitHub 自动提供的 “Source code” 是源码，不是安装包。安装程序尚未签名，系统可能提示未知发布者；请核对来源和校验值，不要关闭安全防护。

## 安装时会做什么

安装包自带 Electron、Python 3.14.7 和固定版主工作流，不要求使用者先装 Node、pnpm 或 Python。主工作流自动进入 `CODEX_HOME/skills/cyz-edu-research`；未设置 `CODEX_HOME` 时，进入当前用户的 `.codex/skills/cyz-edu-research`。

已有主 Skill 内容一致则复用；有不同内容则保留并提示，不直接覆盖。安装不会开始研究任务，也不会携带或修改 Codex 登录信息。卸载移除程序和快捷方式，不主动删除外部研究项目或 Skill。请把项目放在独立文件夹，不要放进程序安装目录。

## 第一次打开怎么用

1. 点击“打开或新建项目”，选择一个独立的空文件夹。已有项目则选择原项目目录。
2. 到“草稿编辑”写几句话并保存，确认本地读写正常。
3. 开始研究对话前，确认本机 Codex CLI 已安装并登录；工作台复用该账号，研究会消耗账号额度。
4. 要解析 PDF，先准备本机 MinerU Desk 0.3.1 和本地模型。在“文献材料”导入 PDF，检查解析样本后再继续全文解析。

`humanizer-zh`、`humanizer`、MinerU Desk 和模型不随安装包提供。中文、英文语言检查需要对应 Skill 和依赖核验；主工作流安装成功不代表这些环节已经可用。两仓库的分工、固定版本和准备方法见 [依赖说明](https://github.com/chengyingzh433-stack/cyz-edu-research/blob/main/docs/workbench-and-workflow.md)。

## 已有功能和限制

目前可用的功能包括材料导入和去重、草稿历史版本、证据矩阵编辑、Codex 研究对话、候选成果确认保存，以及本机 MinerU PDF 解析接入。界面中的阶段导航不代表阶段已验收，任务运行结束也不代表论文事实和引文已核对。

原版 PDF 图文对照、项目备份恢复、一键更新、本机 Agent API、完整审批验收和 S0–S8 完整研究示例尚未完成。当前阅读区展示解析文字，不会自动让模型读到 PDF 原件或全部图表。

本机已通过 107 项自动测试，并实测安装、自定义中文目录、快捷方式、新建项目、保存重启和卸载保留。尚未在另一台全新 Windows 机器上验证，也未完成安装向导逐页视觉核对。详细范围见 [安装版验收记录](https://github.com/chengyingzh433-stack/cyz-research-workbench/blob/main/docs/acceptance/2026-09-19-installer.md)。
