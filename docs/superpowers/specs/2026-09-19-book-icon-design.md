# 书本图标

用户指定艺术化书本，沿用当前墨绿色品牌。以略微展开的暖白书页、非对称翻页曲线和暖金书签构成；不放字母或细小文字。相比写实书封和复杂插画，这个方向在 16–32 像素仍可辨认。

在本地创作 SVG 源文件，使用本机 Electron 渲染为多尺寸 PNG/ICO。界面品牌、窗口和托盘共用同一图形。用户已要求自主继续，不再追加确认步骤。禁止上传或发布。

验证：SVG 在界面正常加载；PNG 256 像素、ICO 含 16/24/32/48/64/128/256 七种尺寸；构建复制到分发目录；目视检查大尺寸及任务栏尺寸。开发环境的 Electron EXE 文件本身不重写，未来本地打包时再使用 ICO 作为可执行文件图标。
