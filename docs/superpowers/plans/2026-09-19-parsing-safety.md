# 本地解析保护实施计划

使用 executing-plans 在当前开发分支执行。用户要求不上传、不发布、不使用子智能体或目标模式，不另开工作区。

目标：样本和配套资产发生变化时不继续使用；解析调用结束并保存任务记录前不允许退出；未知提交仅核实已存在任务。

技术：现有 SQLite、Node 文件校验、Electron 生命周期与 MinerU Desk 本地查询，不加依赖。

## 1. 样本校验

- [ ] 在 `tests/integration/conversions.test.ts` 生成 sample_review，修改 sample.md，断言 readConversion 与 approveSample 均拒绝，submit 次数保持 1。
- [ ] 运行专项测试，确认原实现错误接受修改后的样本。
- [ ] `conversions.ts` 保存样本时将正文 SHA-256 写入已有 paperHash；读取及批准前验证。全文完成后 paperHash 更新为全文指纹。无旧指纹的样本不能自动信任。
- [ ] 运行原有解析测试，确保重复提交保护与全文正文读取不变。

## 2. 配套资产

- [ ] 新增真实文件测试：生成带 assets 图片的规范缓存，修改图片后 readConversion 拒绝。
- [ ] 新增 `conversion_files` 表保存规范缓存文件相对路径和指纹，最终完成状态与清单在一个事务中写入。
- [ ] 扫描拒绝链接和超限文件，读取时逐项校验；没有旧资产清单时不凭当前内容补签。
- [ ] 补测缺失、路径越界和旧缓存清单缺失，运行类型检查及集成测试。

## 3. 退出保护

- [ ] Electron 测试用受控的本地未完成操作验证 app.quit 被阻止，操作结束后可退出。
- [ ] 将 pendingOperations 检查统一放入 before-quit，托盘退出解释正在保存解析状态；不得自动取消共享 MinerU 任务。
- [ ] 验证关闭窗口、正常退出与原研究任务保护仍工作。

## 4. 未知提交核实

- [ ] 读取本机 Desk state/task 的实际字段，仅通过原件路径、唯一输出根及原请求选项匹配任务。
- [ ] 测试唯一匹配恢复、无匹配保持未知、多匹配保持未知；核实过程 submit 调用次数不增加。
- [ ] 在受限 IPC 及材料页增加核实按钮，保留错误原因，不增加直接任意路径或路由入口。
- [ ] 用已完成的合成样本做只读验证，不重新解析或调用模型。

## 5. 收尾

- [ ] typecheck、unit、integration、build、Electron 全部运行；主智能体复核差异。
- [ ] 更新本地文档及验收记录，保存本地提交；不 push、不建发布、不改变已有公开工作流。
