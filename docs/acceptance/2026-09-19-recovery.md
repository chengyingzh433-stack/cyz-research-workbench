# 写入保护与恢复核实

本批新增三项真实跨进程测试：占用期间拒绝第二进程、持锁进程强制退出后可打开、同 ID 不同路径的副本不能并发写入。使用独立 SQLite 排他锁连接，不以 PID 或超时删除锁文件猜测所有权。

七项恢复服务测试覆盖精确会话/轮次/目录匹配、终态恢复、重复核实不重复消息、仍运行、读取失败及缺失会话。Electron 新增一个恢复界面用例。该批不以这些测试替代完整 WB/E 验收。

真实接入报告 `codex-recovery-probe.json`：先运行一轮短回复，然后模拟本地状态未知和缺失回复，断开后用只读查询恢复。结果 completed，找回预期回复，任务数量仍为 1，恢复阶段新发起模型轮数为 0。

边界：找不到轮次或运行时仍报告非终态，继续保留 reconciling；没有强制把未知任务改为完成，也不自动重发。运行时查询并不能证明所有异常都可恢复。项目锁是本机应用写保护，不禁止用户用其他编辑器改正文。
