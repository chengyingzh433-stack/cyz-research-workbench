# 本地解析保护验收

本批只保存在本地，不上传、不发布、不启用子智能体或目标模式。

## 已完成

- 样本读取及全文批准前校验正文指纹，修改后的样本不能继续使用。测试先复现旧逻辑错误放行，再验证修复。
- 全文完成时，将规范缓存的逐文件指纹与完成状态在同一事务登记；读取时核对文件集合及内容。图片被修改、缺失、目录链接均被拒绝。扫描限制为 8 层、5000 项、单文件 20 MB、总量 256 MB。
- 缺少旧校验清单时明确拒绝，不静默补签或删除。旧缓存的交互式再核验工具尚未交付。
- 材料操作及解析状态保存期间，before-quit 阻止退出。Electron 用受控未完成本地操作复现旧实现放行，再验证新实现阻止退出；操作完成后正常关闭。
- 材料页增加“核实解析状态”。核实限定原件路径、专属输出根、解析参数和已知任务 ID；匹配为零或多项时保留未知。只恢复跟踪，不增加解析提交。
- 覆盖小样本响应丢失、全文响应丢失、错误输出根、不同参数及已登记任务 ID 不可替换。
