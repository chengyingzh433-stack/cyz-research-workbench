# 本地书本图标验收

- 自行绘制矢量书本，墨绿底、暖白书页、金色书签。没有上传文件或调用图片服务。
- `apps/desktop/public/icons/book.svg` 为源文件；PNG 和 ICO 由 `pnpm exec electron scripts/build-icons.cjs` 在本地渲染。
- ICO 包含 16、24、32、48、64、128、256 七种尺寸。界面品牌、BrowserWindow 和 Tray 均接入同一图标；构建由 Vite 复制 public 资产。
- 已目视检查 256 像素图标、24 像素缩略图及实际工作台截图。界面测试检查图标可见且加载成功。
- typecheck、构建、27 项单元、60 项集成和 7 项 Electron 测试通过，共 94 项。
- 当前尚无打包后的独立 EXE，未改写 Electron 开发运行器的文件图标；以后本地打包可复用此 ICO。
