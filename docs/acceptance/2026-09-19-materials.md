# 本地材料解析纵切片验收

日期：2026-09-19。工作台为开发版本，本记录不关闭完整 WB/E 验收。

## 已验证的行为

- 同一来源的已有解析不会重复提交；样本核对前不提交全文。
- 全文请求省略 `pages`。真实 Desk 0.3.1 不接受 `pages:null`，回归测试已先失败、修复后通过。
- 仅在离线设置满足时提交；任务 ID 或源路径不符时保留待核实状态。
- 提交响应丢失时保留记录，不自动重新发起。
- 阅读和研究任务准备均校验原件、正文与来源映射的哈希；缓存被改动时停止读取。
- 完整解析文字复制进研究工作副本，保留来源 ID、原件 SHA-256 和初始正文哈希。未修改的阅读副本不进入候选成果列表。
- 研究上下文明确排除原 PDF 和图片，不能声称模型已看过图表。上下文总量仍受 10 MiB 上限约束。
- Electron 材料页可展示已核验正文、解析范围与页码选择。已目视检查三栏布局。

- 阅读区目前展示 Markdown 文字，不是内置原版 PDF 阅读器，也不直接呈现缓存图片。
- 解析提交状态未知后的自动对账、解析中退出托盘的生命周期保护、样本缓存哈希和资产逐文件完整性保护仍需补齐。
